# Palmer Penguins - Introduction to AI coursework
This coursework was completed as a part of my introduction to AI unit in my Data Science MSc. It applies regression and classification techniques to the Palmers Penguins dataset.

The project includes:
- Regression using Lasso-regularised linear models
- Classification using K-Nearest Neighbours and Random Forest
- Evaluation using RMSE, accuracy, and confusion matrices
- A short essay on ethical considerations in AI

## Contents

- `penguins regression classification.py` — Python script used for data cleaning, modelling, and visualisation
- `report AI.pdf` — Full write-up including plots, methods, evaluation, as well as an ethics section (section 4). This section is formulated as a response to a university provided prompt and fulfils the assessment requirements.
